Redefining Travel Planning

LuxeTravel was built with one mission: to make planning a trip as enjoyable as the trip itself.

The Project

This application was developed as a Final Front-End Project. It demonstrates advanced DOM manipulation, state management, drag-and-drop interfaces, and local storage persistence — all without any external frameworks.

Tech Stack: HTML5, Modern CSS (Flexbox / Grid / Custom Properties), Vanilla JavaScript ES6+.
